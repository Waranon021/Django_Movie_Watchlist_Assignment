ABOUT

[ What does this project do? ]

Movie Watchlist allows users to add, edit, delete, search, and organize movies into Plan to Watch and Watched sections. Movies can be entered manually or imported from TMDB with movie metadata and poster images.

[ Main features ]

Watchlist Management

Add, edit, delete, search, and organize movies stored in PostgreSQL using the Django ORM.

Watched Status

Move movies between Plan to Watch and Watched without creating duplicate Movie records.

Personal Rating

Rate watched movies from 1 to 5 directly from the Movie Watchlist interface.

TMDB Integration

Search the TMDB catalog and import movie titles, release years, genres, and poster information.

[ Technology stack ]

- BACKEND: Python / Django
- DATABASE: PostgreSQL
- DATABASE ACCESS: Django ORM
- FRONTEND: HTML5 / Custom CSS
- INTERACTION: Vanilla JavaScript
- HTTP CLIENT: Requests
- EXTERNAL API: TMDB API
- VERSION CONTROL: Git / GitHub

[ API data source ]

Movie information and poster images used by the external movie search feature are retrieved using The Movie Database (TMDB) API.

This product uses the TMDB API for learning purposes only.
